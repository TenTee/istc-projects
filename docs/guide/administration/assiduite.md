# Assiduité (absences et retards des étudiants)

**Menu :** Pédagogie → Assiduité — **Accès :** domaine *Pédagogie*.

## Enregistrer une absence ou un retard

![La page Assiduité](../../images/captures/20_assiduite.jpg)

![Le formulaire d'enregistrement d'une absence ou d'un retard](../../images/captures/20b_assiduite_ajout.jpg)

1. Cliquez sur **Ajouter une absence / un retard**.
2. Remplissez :

    | Champ | Remarque |
    |---|---|
    | Étudiant | Tapez les premières lettres du nom. |
    | Cours (Module) | Cours manqué. |
    | Date | |
    | Type | Absence ou Retard. |
    | Minutes de retard | Pour un retard uniquement. |
    | Justifié | Cochez si l'étudiant a fourni un justificatif. |

3. Enregistrez.

## Suivre et notifier

Le tableau affiche : Date, Étudiant, Cours (Module), Type, Retard (min), statut du justificatif, Justificatif, Parent, Actions.

- L'icône **Notifier le parent via WhatsApp** ouvre WhatsApp avec un message pré-rempli adressé au numéro du parent enregistré dans le dossier de l'étudiant. Vérifiez le message puis envoyez-le depuis WhatsApp.
- Quand un justificatif est apporté, modifiez la ligne et cochez « Justifié ».
- La corbeille supprime une saisie erronée (avec confirmation).

L'étudiant voit ses absences et retards dans son portail, rubrique **Assiduité**.
