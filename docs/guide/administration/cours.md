# Cours et modules

**Menu :** Pédagogie → Cours — **Accès :** domaine *Pédagogie*.

Un **cours** (ou module, ou matière) est une unité d'enseignement notée : *Algorithmique*, *Comptabilité générale*… Les cours sont utilisés par l'emploi du temps, la saisie des notes, les relevés, les épreuves et les documents de cours.

## Créer un cours

![La liste des cours, avec le bouton « Nouveau cours »](../../images/captures/12_cours_liste.jpg)

![Le formulaire « Ajouter un cours »](../../images/captures/12b_cours_ajout.jpg)

1. Cliquez sur **Nouveau cours**.
2. Remplissez :

    | Champ | Exemple | Utilité |
    |---|---|---|
    | Nom du cours | Algorithmique | Affiché partout. |
    | Classes rattachées | Développement Web Licence 1 | Classes qui suivent ce cours (plusieurs possibles). Le cours est proposé pour ces classes dans les listes (notes, emploi du temps). |
    | Durée (heures) | 60 | Volume horaire prévu. |
    | Coefficient | 3 | Poids du cours dans la moyenne. |
    | Semestre | Semestre 1 | Période du cours ; sert à filtrer les relevés. |

3. Cliquez sur **Enregistrer**.

## Modifier ou supprimer

Utilisez le crayon (modifier) ou la corbeille (supprimer). Supprimer un cours qui a déjà des notes est déconseillé.

## Affecter un formateur à un cours

L'affectation se fait de deux façons :

- **méthode recommandée** : en créant un **créneau d'emploi du temps** (cours + classe + formateur), voir [Emploi du temps](emploi-du-temps.md) ;
- à défaut de créneau : en renseignant les **Spécialités (Modules)** du formateur dans sa fiche (voir [Enseignants](enseignants.md)) ; le formateur est alors rattaché à toutes les classes rattachées à ces cours.

Le formateur voit alors la classe dans **Mes Classes** et peut saisir les notes de ce cours.
