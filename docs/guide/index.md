# Guide d'utilisation

Ce guide explique, écran par écran, comment utiliser SmartCampus **sans aucune connaissance technique**.

## Par où commencer ?

1. Lisez [Premiers pas](premiers-pas.md) : se connecter, se repérer dans l'écran, choisir l'année académique, se déconnecter.
2. Lisez [Rôles et droits d'accès](roles-et-acces.md) pour comprendre pourquoi certains menus n'apparaissent pas pour vous.
3. Allez ensuite directement à la partie qui vous concerne :
    - [Administration](administration/index.md) (direction, secrétariat, scolarité, comptabilité, RH, logistique) ;
    - [Portail formateur](portail-formateur.md) et, si vous êtes désigné coordonnateur, [Coordonnateur de filière](coordonnateur.md) ;
    - [Portail étudiant](portail-etudiant.md) ;
    - [Préinscription en ligne](preinscription-candidat.md) pour les candidats.

## Ordre conseillé pour une première mise en service

Si l'établissement démarre sur la plateforme, suivez cet ordre (détaillé dans [Démarrer une nouvelle année](demarrer-une-annee.md)) :

1. **Système** → Apparence & École : nom, logo, couleurs, coordonnées de l'établissement.
2. **Système** → Paramètres Globaux : cycles (Licence, BTS…), horaires de la journée et pause, pourcentages CC / SN.
3. **Système** → Rôles puis Utilisateurs : comptes du personnel administratif.
4. **Pédagogie** → Structure Académique : année académique active, filières, spécialités, niveaux, classes, salles.
5. **Pédagogie** → Cours : les modules enseignés et leurs coefficients.
6. **Enseignants** : les formateurs, leurs comptes portail, puis **Coordonnateurs**.
7. **Finances** → Scolarité → Configuration des Frais : frais d'inscription et échéancier de scolarité de chaque classe.
8. **Pédagogie** → Emploi du temps : les créneaux de cours.
9. Ouvrez la préinscription en ligne aux candidats.

## Conventions utilisées dans ce guide

| Notation | Signification |
|---|---|
| **Finances** → **Scolarité** | Cliquez sur le menu « Finances » à gauche, puis sur le sous-menu « Scolarité ». |
| Bouton **Enregistrer** | Le texte exact du bouton à l'écran. |
| Onglet *Suivi des paiements* | Un onglet en haut de la page. |
| Champ « Montant (FCFA) » | Le nom exact d'une case à remplir. |
| Champ suivi d'un astérisque `*` | Champ obligatoire. |

!!! info "Montants"
    Tous les montants sont en **francs CFA (FCFA)**, sans décimales ni espaces à la saisie (tapez `150000`, pas `150 000 F`).

!!! info "Dates et heures"
    Les dates se saisissent avec le calendrier qui s'ouvre en cliquant dans la case. Les heures sont au format 24 h (`14:30`).
